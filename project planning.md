**Voltra – E-commerce Electronics Store**



**Project Overview**

Voltra is a responsive e-commerce website built with React that allows users to browse and explore a variety of electronic products, including smartphones, laptops, headphones, and accessories.



The website provides product listings, detailed product pages, and a shopping cart where users can add or remove products and update quantities. It also includes a simulated checkout process with form validation.



The project uses a products API to fetch product information dynamically and Redux Toolkit to manage the shopping cart state across the application.



**Project Objectives**

\- Build a modern and responsive user interface.

\- Fetch and display products from a API.

\- Allow users to view product details.

\- Implement shopping cart functionality using Redux Toolkit.

\- Create a checkout form with basic validation.

\- Deploy the application online.



**Technologies Used**

React, JavaScript, HTML, CSS, React Router, Redux Toolkit, REST API, and Vercel or Netlify.
